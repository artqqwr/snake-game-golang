# Snake game

Snake game in Go using [Ebitengine](https://github.com/hajimehoshi/ebiten).

## Возможности

- Главное меню с выбором карты, сложности и поведения при самостолкновении.
- Большой мир `128×128` клеток (видимая область `32×32`) с камерой, которая
  плавно следует за змейкой.
- Пять карт с разными схемами препятствий.
- Еда, счёт и рекорд за текущий запуск.
- Мягкие границы мира: змейка не разбивается о край, а упирается в него и может
  повернуть внутрь.
- Пауза и экран окончания игры.
- Два режима самостолкновения: `Game Over` или «откусить хвост».
- В мультиплеере самостолкновение всегда откусывает хвост, а столкновение с чужой
  змейкой или препятствием смертельно.
- LAN-мультиплеер до 8 игроков: хост, гости, лобби, реванш, подключение по IP
  и ожидание следующего раунда, если игрок подключился во время текущего.
- При столкновении с другой змейкой игрок погибает, а его тело превращается в еду
  (суммарно половина длины). Препятствия тоже смертельны.

## Управление

- `↑ ↓ ← →` или `W A S D` — движение.
- `P` или `Escape` — пауза в одиночной игре.
- В меню `↑/↓` выбирают пункт, `←/→` меняют значение, `Enter` запускает игру.
- Пункт `5 MULTIPLAYER`: `OFF`, `HOST` или `JOIN`.
- `HOST` открывает лобби и ждёт игроков; `Enter` начинает раунд, `Esc` закрывает комнату.
- `JOIN` сканирует локальную сеть. `↑/↓` выбирают комнату, `Enter` подключается,
  `R` повторяет поиск, `I` открывает ручной ввод `IP:PORT`, `Esc` возвращает в меню.
- В сетевой игре паузой управляет хост (`P`), гости видят оверлей.
- На экране результатов хост может начать реванш (`Enter`), `Esc` выходит из комнаты.

## Запуск

### Требования

- Go
- Зависимости Ebitengine: [инструкция установки](https://ebitengine.org/en/documents/install.html)

```bash
go run .
```

Сразу стать хостом или подключиться по адресу:

```bash
go run . -host
go run . -join 192.168.1.10:4040
go run . -host -name "My room"
go run . -host -max 8
```

`-max` задаёт лимит игроков в комнате, включая хоста (`2..8`, по умолчанию `8`).

Проверка проекта:

```bash
go test ./...
go test -race ./...
go vet ./...
staticcheck ./...
```

## Multiplayer

Архитектура — **авторитетный хост**. Хост симулирует всех змеек, еду, счёт, смерти
и паузу, а гости отправляют только намерение поворота и рисуют полученные снапшоты.
Благодаря этому состояние мира не расходится.

- В комнате может быть до 8 игроков, включая хоста.
- Гость автоматически сообщает `ready`. Хост начинает раунд, когда подключён
  хотя бы один гость и готовы все подключённые игроки.
- Подключившийся во время раунда игрок ждёт в лобби и попадает в следующий раунд.
- После смерти игрок становится зрителем: камера следует за лидером, а раунд
  продолжается, пока не останется один живой игрок.
- Если игрок отключился во время раунда, его змейка убирается, а тело становится едой.

Транспорт:

- TCP `4040` — handshake, лобби, `ready`, `start`, `pause`, `disconnect` и информация о комнате.
- UDP `4041` — бинарные `input` и `snapshot` пакеты (компактнее JSON; большие
  снапшоты могут фрагментироваться на IP-уровне).
- UDP `4042` — discovery для поиска комнат в локальной сети.

Если порты заняты, хост пробует следующие (4040–4049, 4041–4049). Discovery —
best effort: при занятом порту 4042 игра продолжает работать, а гости подключаются
вручную по IP. Публичный matchmaking и NAT traversal не поддерживаются: игроки должны
находиться в одной локальной сети либо быть доступны по IP напрямую.

Протокол игры — **v3**. Он несовместим со старыми сборками, поэтому хост и все гости
должны запускать обновлённую версию.
