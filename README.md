# Snake game

Snake game in Go using [Ebitengine](https://github.com/hajimehoshi/ebiten).

## Возможности

- Главное меню с выбором карты, сложности и поведения при самостолкновении.
- Большой мир 128×128 клеток (видимая область 32×32) с камерой, которая
  плавно следует за змейкой.
- Пять карт с разными схемами препятствий.
- Еда, счёт и рекорд за текущий запуск.
- Мягкие границы мира: змейка не разбивается о край, а упирается в него и может
  повернуть внутрь.
- Пауза и экран окончания игры.
- Два режима самостолкновения: Game Over или откусить хвост.
- В мультиплеере самостолкновение всегда откусывает хвост, а столкновение с чужой
  змейкой или препятствием смертельно.
- LAN мультиплеер до 8 игроков (хост, гости, лобби, реванш, подключение по IP).
- При столкновении с другой змейкой игрок погибает, а его тело превращается в еду
  (пол длины змейки).

## Управление

- `Стрелки` или `W A S D` - движение.
- `P` или `Escape` - пауза в одиночной игре.
- Пункт `5 MULTIPLAYER`: `OFF`, `HOST` или `JOIN`.
  - `HOST` открывает лобби и ждёт игроков; `Enter` начинает раунд, `B` добавляет
    одного бота, `Esc` закрывает комнату.
  - `JOIN` сканирует локальную сеть. Выбирать комнату через стрелки, `Enter` подключается,
      `R` повторяет поиск, `I` открывает ручной ввод `IP:PORT`, `Esc` возвращает в меню.
- В сетевой игре паузой управляет хост (`P`), гости видят оверлей.
- На экране результатов хост может начать реванш (`Enter`), `Esc` выходит из комнаты.

## Запуск

### Требования

- Go
- Зависимости Ebitengine: [инструкция установки](https://ebitengine.org/en/documents/install.html)

```bash
go run .
```

Сразу стать хостом или подключиться по адресу:

```bash
go run . --host
go run . --join 192.168.1.10:4040
go run . --host --name "My room"
go run . --host --max 8
go run . --host --max 8 --bots 3
go run . --bots 5              # тож самое что --host --bots 5
```

`--max` задаёт лимит игроков в комнате, включая хоста (`2..8`, по умолчанию `8`).

### Cервер-mode

`--server` запускает авторитетный сервер без окна и без локальной змейки.

```bash
go run . --server
go run . --server --max 8 --bots 5
```

- Сервер сам начинает раунд когда готовы минимум 2 игрока, после короткой
  задержки (3 сек), чтобы люди успели подключиться.
- После результатов (5 сек) следующий раунд запускается автоматически.
- Подключившиеся во время раунда игроки ждут следующий раунд.
- В режиме `--server` значение `--max` - это лимит player-ов на карте (до 8), а в
  обычном `--host` - общий лимит вместе с хостом.

## Multiplayer

Хост симулирует всех змеек, еду, счёт, смерти и паузу, а гости отправляют только намерение поворота и рисуют полученные snapshot ы.

- В комнате может быть до 8 игроков, включая хоста. На выделенном сервере
  сервер не игрок, поэтому доступны все 8 слотов для гостей и ботов.
- Гость автоматически сообщает `ready`. Хост начинает раунд, когда подключён
  хотя бы один гость и готовы все подключённые игроки. Выделенный сервер делает
  это сам, когда готовы минимум два игрока.
- Подключившийся во время раунда игрок ждёт в лобби и попадает в следующий раунд.
- После смерти игрок становится зрителем (камера следит за лидером).
- Если игрок отключился во время раунда, его змейка убирается, а тело становится едой.

### Боты

Боты - это обычные сетевые клиенты, поэтому они проходят тот же путь
`join -> ready -> input -> snapshot`, что и игроки.
- Боты ищут еду, избегают стен, тел змеек, чужих голов и выхода за границу,
  предпочитая ходы с большим доступным пространством.
- В лобби боты помечаются как BOT.

### Транспорт:

- TCP `4040` - handshake, лобби, `ready`, `start`, `pause`, `disconnect` и информация о комнате.
- UDP `4041` - бинарные `input` и `snapshot` пакеты
- UDP `4042` - discovery для поиска комнат в локальной сети

Если порты заняты, хост пробует следующие (4040-4049, 4041-4049).
